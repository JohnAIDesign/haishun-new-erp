# 海顺 New ERP 整合分析

围绕销售订单、工艺配方、BOM、排产、制造、出库和发货，梳理制造企业 AI 与 ERP 转型的业务逻辑、数据基础及实施路径。

## 在线阅读

- [站点首页](https://johnaidesign.github.io/haishun-new-erp/)
- [原页面地址](https://johnaidesign.github.io/haishun-new-erp/AI时代制造企业ERP整合分析.html)

两个 HTML 入口内容相同。使用连续阅读、有标题的目录、企业路径切换及可展开术语表；兼容原数字锚点（如 `#7`）与早期 `#p7` 链接。

## 使用与维护

纯静态 HTML，无构建步骤或外部脚本依赖。直接打开即可阅读。手机端支持表格横向滚动；打印时展示两类企业路径，并在每页右下角显示内嵌的 AI修理工 Logo。

修改内容后应同步 `index.html` 和 `AI时代制造企业ERP整合分析.html`，保证入口一致。厂商接口能力以适用版本的官方资料和实际验证为准。
